# brewery-calendars (compatibility mirror)

This repo exists so calendar subscriptions created before the project was renamed keep working.
The project now lives at **[ByteMasterPro/local-calendars](https://github.com/ByteMasterPro/local-calendars)**
and is published at https://bytemasterpro.github.io/local-calendars/

A scheduled job copies the published `.ics` files from there to here every day, so the old URLs

```
https://bytemasterpro.github.io/brewery-calendars/<name>.ics
```

serve the same, current feeds as the new ones. Nothing is authored here — edit calendars in the
`local-calendars` repo. If every old subscription has been repointed at the new URLs, this repo
can be deleted.
